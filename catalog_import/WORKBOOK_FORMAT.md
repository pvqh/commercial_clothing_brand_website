# Как заполнить файл стартового каталога

Каталог загружается один раз из файла Excel (`.xlsx`). Пустой шаблон со всеми листами и
заголовками: `catalog_import/catalog_template.xlsx`.

## Общие правила

- Один лист на каждую таблицу. В строке 1 точные названия столбцов (как в шаблоне), данные со
  строки 2. Пустые строки пропускаются.
- `*` — обязательный столбец. Текст `_ru` обязателен там, где поле обязательно; текст `_en`
  всегда можно оставить пустым — на английской версии сайта тогда будет русский текст.
- **Ключи** — короткие метки, которые вы придумываете сами (латинские буквы, цифры, `-`), например
  `mink-classic`. Они нужны только чтобы связать строки разных листов и на сайте не видны.
- Цены — целые рубли без копеек и пробелов: `185000`.

## Лист Categories (категории)

| Столбец | Что писать |
|---------|------------|
| category_key* | Уникальный ключ |
| name_ru*, name_en | Название |
| position* | Порядок в меню: целое число от 0 |

## Лист SizeGuides (таблицы размеров)

| Столбец | Что писать |
|---------|------------|
| guide_key* | Уникальный ключ |
| internal_name* | Название для сотрудников, например «Длинные шубы 2026» |
| how_to_measure_ru*, how_to_measure_en | Как снять мерки |

## Лист SizeGuideRows (строки таблиц размеров)

| Столбец | Что писать |
|---------|------------|
| guide_key* | Ключ с листа SizeGuides |
| size* | `xxs`, `xs`, `s`, `m`, `l`, `xl`, `xxl` или `xxxl` |
| chest_cm*, waist_cm*, hips_cm*, sleeve_cm*, length_cm* | Мерки в сантиметрах, больше нуля, один знак после запятой |

## Лист ProductTypes (типы товаров)

| Столбец | Что писать |
|---------|------------|
| type_key* | Уникальный ключ |
| name_ru*, name_en | Название, например «Длинные шубы» |
| guide_key | Таблица размеров для всех товаров этого типа (ключ с листа SizeGuides) |

## Лист Products (товары)

| Столбец | Что писать |
|---------|------------|
| product_key* | Уникальный ключ |
| name_ru*, name_en | Название |
| description_ru*, description_en | Описание |
| care_ru*, care_en | Уход |
| fur_species_ru*, fur_species_en | Вид меха |
| fur_origin_ru*, fur_origin_en | Страна происхождения меха |
| fur_treatment* | `natural` (без окрашивания и обработки), `dyed` (окрашенный) или `treated` (другая обработка) |
| fur_treatment_detail_ru, fur_treatment_detail_en | Описание обработки; `_ru` обязательно для `treated` |
| shell_ru*, shell_en; lining_ru*, lining_en; trim_ru, trim_en | Верх, подкладка, отделка (отделку можно не заполнять) |
| type_key* | Ключ с листа ProductTypes |
| guide_key | Своя таблица размеров для этого товара (если отличается от таблицы типа) |
| categories* | Ключи категорий через запятую; **первая — основная категория** |
| publish* | `yes` — опубликовать сразу, `no` — сохранить черновиком |

## Лист Colors (цвета)

| Столбец | Что писать |
|---------|------------|
| product_key*, color_key* | Ключ товара и ключ цвета (уникальный внутри товара) |
| name_ru*, name_en | Название цвета, например «Натуральный» |
| position* | Порядок: целое число от 0, у каждого цвета товара свой; цвет с 0 выбран по умолчанию |

## Лист Variants (размеры и остатки)

| Столбец | Что писать |
|---------|------------|
| product_key*, color_key* | Ключ товара и ключ цвета с листа Colors |
| size* | `xxs` … `xxxl` или `one` (единый размер). Каждый размер один раз на цвет. Нельзя сочетать `one` с буквенными размерами в одном товаре |
| price_rub* | Цена в рублях, целое число больше нуля |
| stock* | Остаток, целое число от 0 |

## Лист Photos (фотографии)

| Столбец | Что писать |
|---------|------------|
| product_key* | Ключ товара |
| color_key | Ключ цвета; пусто — фото подходит для всех цветов |
| file* | Имя файла в папке с фотографиями: JPEG, PNG или WebP, пропорции 2:3, ширина от 1440 px |
| position* | Порядок в галерее; фото с наименьшим номером показывается в каталоге |
| alt_ru*, alt_en | Короткое описание фото для незрячих покупателей и поисковиков |

## Что происходит при ошибках

| Ошибка | Результат |
|--------|-----------|
| Нет листа или столбца | Загрузка не начинается |
| Каталог уже загружен | Загрузка не начинается |
| В строке товара нет `product_key` или `name_ru` | Строка отклонена, товар не создаётся |
| Любая другая ошибка в строках товара (Products, Colors, Variants, Photos), в том числе нет файла фото | Строка отклонена, товар сохраняется **черновиком** со всеми остальными данными |
| `publish = yes`, но товар не проходит правила публикации | Товар сохраняется черновиком, в отчёте написано, чего не хватает |
| Ключ категории в `categories` не найден на листе Categories | Ключ пропускается, товар сохраняется черновиком |
| Ошибка на листах Categories, SizeGuides, SizeGuideRows, ProductTypes | Строка отклонена; товары, которые на неё ссылаются, сохраняются черновиками |

Все замечания записываются в файл `<имя файла>-report.csv` со столбцами: лист, строка, столбец,
проблема. Черновики можно исправить и опубликовать в разделе для сотрудников `/staff/`.

## Как запустить (делает администратор)

```text
uv run python manage.py import_catalog каталог.xlsx --photos папка-с-фото --run-by admin --dry-run
uv run python manage.py import_catalog каталог.xlsx --photos папка-с-фото --run-by admin
```

Сначала проверка (`--dry-run`) — она ничего не записывает, только показывает отчёт. Потом
загрузка. Категории, в которые попал хотя бы один товар, публикуются автоматически.
